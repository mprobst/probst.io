Does anyone know about an up-to-date XML Schema definition for Atom 1.0? I only found <a href="http://www.kbcafe.com/iBLOGthere4iM/?guid=20030929215131">this one</a>, which is nice, but it doesn't fit the current spec very good, and I'm too lazy to fix it ;-). There must be a (non-RELAX NG) schema out there, or not?

I'm currently playing around with the <a href="http://www.ietf.org/internet-drafts/draft-ietf-atompub-protocol-04.txt">Atom Publishing Protocol</a>, <a href="http://www.ietf.org/internet-drafts/draft-ietf-atompub-format-11.txt">Atom</a> itself and <a href="http://www.xml.com/pub/a/2005/09/21/atom-store-web-database.html">this idea</a> of a Atom-based web storage facility. I'm not completly convinced that it's useful, I mainly wanted to try how hard it would be to implement something like that using X-Hive/DB. Or maybe it's just that XQuery is being finalized, and I need a new quick moving target to complain about changes in the spec ...

Speaking of that, we just released <a href="http://www.x-hive.com/products/db/">X-Hive/DB 7.0</a>, which is really cool. I will probably write some stuff about it later, when the website is properly updated.
