<a href="http://www.macheist.com/">MacHeist</a> offers a software bundle consisting of a set of nice Mac OS X applications for 49$. While I certainly won't need some of the applications, this includes Snapz Pro X, which itself costs 69$ standalone. Other apps include Pixelmator, CoverSutra and CSSEdit, so this is definitely worth looking at.
